# HaloVehicles - Forge 1.20.1

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- [SuperbWarfare](https://github.com/ATSUISHIO/superbwarfare) 0.8.8
- [GeckoLib](https://github.com/bernie-g/geckolib) 4.x

## Vehicles

| Vehicle | Description |
|---------|-------------|
| M12 | Base Warthog vehicle |
| M12HMG | Warthog with Heavy Machine Gun |
| M12ROC | Warthog with Rocket Launcher |
| M12GAU | Warthog with GAU Gatling Gun |
| M12TRA | Warthog Transport variant |
